# Portofolio Digital - Raka Darahman (Hardware Engineer)

Website portofolio statis yang modern, ringan, dan responsif. Dibangun khusus untuk kebutuhan melamar pekerjaan di bidang **Hardware Engineering**.

## 🛠️ Teknologi yang Digunakan
- **HTML5** (Semantik & SEO friendly)
- **Tailwind CSS** (via CDN - tanpa perlu instalasi `npm` atau build step yang rumit)
- **Lucide Icons** (Ikon vektor modern untuk perangkat keras & UI)
- **Vanilla JavaScript** (Dark mode toggle, mobile navigation drawer, smooth scrolling)

## 📁 Struktur File
```text
kaaa/
├── index.html       # File utama portofolio
└── README.md        # Panduan penggunaan & hosting
```

## 🚀 Cara Melihat Portofolio di Komputer Lokal
Cukup klik ganda (double click) file `index.html` pada File Explorer Anda, atau buka melalui browser apa saja (Chrome, Edge, Firefox).

---

## 🌐 Cara Hosting Gratis (Online)

### Opsi 1: GitHub Pages (Paling Direkomendasikan)
1. Buat repository baru di GitHub (misal: `portofolio-hardware`).
2. Upload file `index.html` ke repository tersebut.
3. Buka tab **Settings** > **Pages** di repository Anda.
4. Pada bagian **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
5. Website Anda akan langsung online dengan alamat gratis: `https://username.github.io/portofolio-hardware/`.

### Opsi 2: Netlify Drop (Paling Cepat / Tanpa Git)
1. Buka [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag & drop folder `kaaa` ini langsung ke jendela browser.
3. Website akan langsung aktif dalam hitungan detik dengan URL publik.

### Opsi 3: Vercel
1. Hubungkan akun GitHub Anda ke [vercel.com](https://vercel.com).
2. Import repository proyek ini, lalu klik **Deploy**.
